# Marka görseli

## bizzat-brand-board.png

Bu görüşmede hazırlanan ve kullanıcı tarafından beğenilen görsel yönün, güncel sloganla düzenlenmiş marka panosudur.

- Ana slogan: **Bireysel ilanların adresi.**
- İletişim çağrısı: **İlan verenle görüş.**
- Görünüm: Açık mavi küçük harfli yazı logosu; beyaz zemin ve açık tonlu yardımcı alanlar.
- Tür: PNG, raster tasarım referansı.

Görsel, düzenlenebilir vektör logo veya kesin font dosyası değildir. Kaynak çalışmadaki onaylanan tasarım korunmuştur. Üretim dosyaları hazırlanırken [DESIGN.md](../../DESIGN.md) esas alınır.

Eski sloganı taşıyan ilk taslaklar, güncel kimlikle karışmaması için bu klasöre alınmadı.
